# Guia de Contribucion - TaskFlow API

¡Gracias por tu interes en contribuir a TaskFlow API!

## ¿Como reportar un error o proponer una mejora?
- Revisa los **Issues** existentes para no duplicar reportes.
- Si encuentras un fallo, abre un nuevo **Issue** detallando los pasos para reproducirlo.

## Proceso de Pull Request (PR)
1. Realiza un **Fork** de este repositorio.
2. Crea una rama para tu funcion: `git checkout -b feature/nueva-funcionalidad`
3. Realiza tus cambios y confirma los avances: `git commit -m "feat: agrega nueva funcionalidad"`
4. Sube tu rama a GitHub: `git push origin feature/nueva-funcionalidad`
5. Abre un **Pull Request** explicando detalladamente los cambios realizados.

## Lista de verificacion para PRs
- [ ] El codigo ejecuta localmente sin errores.
- [ ] Se incluyeron o actualizaron las pruebas unitarias.
- [ ] Se actualizo la documentacion en el `README.md` si aplica.
